## Project: EduGenie AI - Personalized Learning

### Problem Statement
Students struggle to get personalized learning support, doubts clearing is delayed, and study materials are scattered.

### Proposed Solution
EduGenie AI - An AI-powered assistant that provides instant doubt solving, personalized study plans, and curated resources.

### Objectives
- Provide 24/7 AI doubt support
- Create personalized learning paths
- Recommend videos, notes, quizzes
