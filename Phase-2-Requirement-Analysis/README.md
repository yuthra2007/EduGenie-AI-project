# Phase 2 - Requirement Analysis

## Functional Requirements
- User login / registration
- Ask doubts via text
- AI generates answers instantly
- Study plan generation
- Resource recommendation

## Non-Functional Requirements
- Fast response < 3 sec
- Mobile friendly
- Secure data handling
- 24/7 availability

## User Stories
- As a student, I want to ask my maths doubt and get instant solution
- As a student, I want personalized timetable for exams

## Tools & Dataset
- Python, OpenAI API, GitHub
- NCERT dataset, YouTube educational APIs
